# 🚀 Projeto Nexfusion-Carga Volátil

Um jogo onde você é um cientista preso no seu próprio laboratório e precisa sobreviver a hordas de mutantes zumbis! Seu único meio de defesa é uma pistola — mas, felizmente, não uma qualquer! Você usa seu conhecimento científico para modificá-la, utilizando elementos químicos como munição e EXPLODINDO TUDO!!!
